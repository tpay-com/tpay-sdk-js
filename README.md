# Tpay SDK Monorepo

This repository contains all the official Tpay JavaScript/TypeScript SDKs.

## Packages

This is a monorepo managed with [Nx](https://nx.dev). The packages are located in the `packages/` directory.

| Package                                                     | Description                            |
| ----------------------------------------------------------- | -------------------------------------- |
| [`@tpay-com/click-to-pay-sdk`](./packages/click-to-pay-sdk) | SDK for Tpay Click to Pay integration. |
